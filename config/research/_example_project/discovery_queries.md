# Discovery Queries — Example Project

Fictional example queries for cloud backup vendor research.

## Primary Objective

Find cloud backup vendors suitable for a small team needing JP/US coverage,
API integration, and transparent pricing.

## Query Examples (English)

- cloud backup service API SSO
- enterprise backup Japan US data residency
- SaaS backup point in time restore pricing
- backup vendor SOC2 encryption at rest

## Query Examples (Japanese)

- クラウドバックアップ API 連携
- バックアップ サービス 日本 米国
- エンタープライズ バックアップ SSO

## Geographic Search

Search separately when relevant:

- Japan
- United States
- APAC

## Verification Priority

For each serious candidate verify separately:

1. Operating status
2. Core backup service (not unrelated product)
3. Geographic availability
4. Encryption claims
5. API availability
6. Pricing transparency
7. Support channels

## Important

Never infer capability from vendor name, category placement, or search ranking.

If a capability cannot be verified, mark UNKNOWN.

Do not assign YES without supporting evidence.
