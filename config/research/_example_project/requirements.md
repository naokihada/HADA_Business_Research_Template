# Requirements — Example Project (Fictional)

## Research Context

A fictional small software team needs a cloud backup vendor for production
workloads. This file represents user requirements stored in master data.

## Must Have

- Cloud backup with point-in-time restore
- Service available in Japan and United States
- Encryption in transit and at rest (verified from official source)
- Admin console for restore operations

## Should Have

- API for automation
- Enterprise SSO (SAML or OIDC)
- Public pricing or pricing calculator
- Email or chat support with documented response expectations

## Nice to Have

- Immutable backup option
- Cross-region restore
- Japanese language support documentation

## Constraints

- Prefer monthly or annual contract flexibility
- Avoid vendors with no public technical documentation
- Decision target: shortlist of 2–3 vendors for trial evaluation

## Not In Scope

- On-premises backup appliances
- Personal consumer backup only (no team admin features)

## Engagement Process

1. Shortlist from evidence-based research
2. Request trial or proof of concept
3. Validate restore workflow before final selection
