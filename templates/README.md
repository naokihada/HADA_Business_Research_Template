# Templates

Reusable Markdown and CSV templates for the generic research engine.

Copy templates into active research paths — do not edit these master templates
in place during a research project.

| File | Purpose |
|---|---|
| candidates_master.csv | Master candidate CSV header |
| candidate_dossier.md | Per-candidate research record |
| evidence_record.md | Claim and source evidence |
| research_log.md | Append-only research log table |
| qc_result.md | QC module per-candidate result |
| scoring_results.csv | Scoring CSV header (extend with dimension columns) |
| unified_ranking.csv | Multi-wave unified ranking CSV header |
| shortlist.md | Shortlist output |
| report.md | Final report shell |

Dimension columns in scoring CSV are declared in project scoring_rubric.yaml —
not fixed in the base header template.
